### 你好，我是 佳侣 👋

我在做 AI 产品，始终关心一件事：**让 AI 帮人想得更清楚，而不是替人做决定。**

好的工具应该让人越用越有判断力，而不是越来越依赖它。所以我做的东西更多是在提问、整理和提醒，最后的判断留给人自己。
