#### 📚 [Readwise](https://github.com/currycham/readwise) · 让读过的书成为你的一部分
**https://readwise.waywise.tech**

读完一本书，过几个月往往只剩一个书名。Readwise 用《如何阅读一本书》和《学习之道》的方法，为每本书生成一份回顾：
- **双人播客**：两位主持人用 20 分钟把整本书聊一遍，通勤路上就能听完
- **限时精读**：按 5 / 40 / 5 / 10 分钟的节奏，读核心观点、做主动回忆
- **闯关检测**：用题目检验是否真的读懂，而不是"好像看过"
- **向作者提问**：拿书里的观点去追问自己的处境
- **书籍网络**：3D 知识星图，展示书与书之间的呼应、对话、互补和传承

#### 📈 [InvestWise](https://github.com/currycham/investwise) · 替你盯住持仓的投资助手
**https://investwise.waywise.tech**（邀请制内测）

真正难的不是找信息，而是在噪音里认出那几条会改变公司价值的事：
- **每日跟踪**：每天早上抓取持仓公司的新闻和公告，去掉噪音，合并同一事件
- **框架打分**：从价值、成长、管理层、催化剂与风险四个角度评分，并对照你写下的"我为什么买它"
- **预警**：重要变化或买入逻辑被证伪时置顶提醒，并发邮件
- **苏格拉底式提问**：AI 不给买卖建议，而是像投委会主席一样追问你逻辑里最薄弱的一环
- **可追溯**：每条结论都附原始来源，模型编造的来源一律丢弃
