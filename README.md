### 你好，我是 佳侣 👋

我在做 AI 产品，也把做产品当成一种表达：像写作一样，有的写给自己，有的写给朋友，有的写给更多的人。

我想做的东西，不替人做决定，也不保证让事情更轻松，只陪人把一件事想得更透一点。不期待很多人用，只希望遇见同样还在寻找些什么的朋友。

> 我没有去看，而是去寻找。
